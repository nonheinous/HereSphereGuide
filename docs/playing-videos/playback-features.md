# Playback features

- **Seeking:** set seek jump times in *User settings*, including a percentage-of-duration option [2024-11]. If a seek jump ignores your setting, another binding is probably assigned to the same button [2022-11].
- **Playback speed increment:** *User settings*, bottom left. It multiplies the default 0.5 [2023-02].
- **FPS display:** top right of the seekbar menu [2023-08].
- **Playlists:** click *Playlists* in the left panel; the pencil icon renames one [2023-01]. For very large playlists, saved searches load faster [2022-12].
- **Compilations:** use video tag autoseek to play time ranges across videos in sequence. See [Media library and tags](../library/media-library-tags.md) [2025-10].

## Multiscreen

Multiscreen plays several videos at once in a grid [2022-07], [2024-10].

1. Play a flat (perspective projection) video. Click the nine-tile icon at the bottom left of the playback controls.
2. Set rows and columns in *Advanced video settings*.
3. To control a screen, hide the menu, face that screen, and open the menu or use the next-video binding.
4. Audio follows the screen you face. Turn off *Auto switch audio* to lock it, or turn on *Play all screens* under audio in *User settings*.
5. The nine-arrows icon next to the multiscreen icon controls all screens at once.

More than five screens work on current versions. Nine 1080p videos play on Quest 3, but several 4K videos may run out of memory [2024-10].
