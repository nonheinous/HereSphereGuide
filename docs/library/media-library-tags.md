# Media library and tags

The Media Library records every video you've played, grouped by media source: each folder, share, or website. Click *Media Library* in the left panel to manage sources [2021-11].

## Managing sources

- **Hide a source** from *All Media*: open *Media Sources* and toggle its eye icon [2024-01].
- **Remove a video's saved settings:** delete it from the Media Library without choosing *permanently delete file* [2022-06].
- **Rescan a folder,** including HSP files: open the source and press the circular-arrow icon, upper left. Recommended on PC; it may crash Quest on large folders [2024-02].

## Tags and search

- **Tag categories:** name a tag `Category:Tag` to group it [2021-09].
- **Exclude a tag in search:** prefix it with a minus, like `-MyTag` [2024-01].
- **Save frequent searches** as favorites [2022-12].

## Creating timed tags

[2025-10]

1. Open the video tags menu and add a track.
2. Name the tag, seek to the start, and press *Update start*.
3. Seek to the end and press *Update end*.
4. Add more tags to the same track as needed.

## Autoseek

Autoseek jumps between tags, including across videos, which works for building compilations. Bookmark tags in the autoseek tags menu to switch between them. Looping is not tied to tags [2024-08].

To change video settings at a point in a video, use keyframes (the key icon on a settings group) rather than tags [2024-04].
