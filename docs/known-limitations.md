# Known limitations

Features users often ask for that aren't supported yet, with the status the developer last gave. Update this page with each release.

| Feature | Status last stated |
| --- | --- |
| Photos on Quest and PC | Planned for next major update; supported on AVP [2026-07] |
| USB storage on Quest | Low priority [2026-02] |
| Streaming from a PC over USB cable | Not supported; use the network [2026-02] |
| Skip unsupported files automatically | On to-do list [2024-11] |
| Pico 4 Ultra | No progress [2025-06] |
| Horizontal flip on Quest | On to-do list; available on PC [2023-12] |
| Moving a 2D screen vertically | Planned for UX update [2025-03] |
| Screenshots | Not supported [2025-02] |
| Masking part of a video for passthrough | Not supported [2024-02] |
| Denoising | Not supported [2023-09] |
| Microphone in the in-app browser | Not supported [2025-11] |
| Native Lovense support | Not supported; use the timestamp server [2025-09] |
