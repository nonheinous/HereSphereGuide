# Presets and per-video settings

Every change you make is saved for that video automatically, and loads again next time you play it [2021-07].

## Changing the default for new videos

1. Adjust the setting.
2. Click that group's header (*Image*, *Origin*, and so on) to show its presets.
3. Save over the first preset in the list [2022-12], [2026-04].

New videos load the first preset of each group, except *Global* and *Format*. Those have no default because format is detected from the filename or the video itself [2023-01].

*Resolution* persists across videos on its own [2026-04].

## Resetting

- Reset one setting: hover over it and click the thumbstick or press A / X [2022-10].
- If you overwrote a default preset, reset each setting this way, then save over the first preset again [2022-10].

## Sharing and moving settings

Per-video settings can be saved as HSP files that travel with the video. See [Saved data, HSP files and backups](../library/saved-data-backups.md).

The settings group headers can be collapsed with buttons at the bottom of the window [2026-06].
