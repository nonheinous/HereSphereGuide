# Controls and key bindings

The fastest way to learn any setting is its tooltip: hover over it and hold the grip button [2025-06]. The in-app user guide at the bottom of the left side panel covers projection setup in detail.

## Default controls (Quest, menu hidden)

| Action | Default control |
| --- | --- |
| Show or hide menu | B / Y |
| Play / pause | A / X |
| Rotate screen | Hold trigger and move controller |
| Zoom in / out | Thumbstick up / down |
| Seek back / forward | Thumbstick left / right |
| Adjust the hovered number box | Hold grip + thumbstick |
| Recenter orientation and origin | Hold grip + click thumbstick (or top face button) |
| Reset a setting to default | Hover it and click thumbstick or press A / X |

Sources: [2024-11], [2026-07], [2026-03].

## Layers

Holding grip activates key layer 1, which gives every button a second function, like a Shift key. Bind extra actions on a layer rather than replacing defaults. Removing grip as the layer 1 button breaks grip-based shortcuts [2023-11].

## Recentering

Recenter only works with the menu hidden, to avoid conflicts with menu controls. There is also a recenter icon (a dot in a box) at the bottom left of the seekbar that recenters after a countdown [2026-07].

To bind recenter to another button, set the binding to layer 0, click the gamepad icon, and press the button to detect it [2026-07].

## Zoom speed

In key bindings, find *Increment Origin Forward* and raise its scale. Use this one, not *Move Origin Forward*, which follows head direction [2024-04].

## Screen drifting on its own

This usually means thumbstick drift on the controller. Check for non-zero values in the rotation or origin settings, and adjust the headset's thumbstick deadzone if it has one [2026-07].

## Menu size

Increase *Menu view arc* in *User settings* [2024-10].
