# Contributing

Corrections and additions are welcome. The most useful contributions confirm or update instructions against the current version of HereSphere.

## Writing guidelines

- **Say which platform an instruction applies to** when it isn't all of them: Quest, PC, or AVP (Apple Vision Pro).
- **Date your source.** Add the month the information was confirmed in brackets, like `[2026-09]`. If you verified it yourself in the app, note the app version too, like `[2026-09, v0.12.2]`.
- **Use exact menu labels** in italics, like *Advanced video settings*, so readers can match them in the app.
- **Keep it neutral.** Describe settings and features. Don't link to or name adult content beyond what's needed to identify a lens or camera format.
- **Screenshots** should show the HereSphere interface with neutral or test footage only. GitHub prohibits sexually explicit content.

## Reporting a problem

Open an Issue with the page name, what's wrong, and your platform and app version.

## Unanswered questions

Questions from the Discord channel that never got an answer are good candidates for new content. If you know the answer, open an Issue or a pull request.
